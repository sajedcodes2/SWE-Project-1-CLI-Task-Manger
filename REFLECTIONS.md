# Reflections

1. Share one aspect of building this project you found challenging and how you
   overcame it.

[ One challenging aspect of building this project was when I was implementing the high-score leaderboard. I initially struggled with understanding how to store player information in dictionaries, sort the scores from highest to lowest, and limit the leaderboard to the top three players. I overcame this by breaking the problem into smaller steps, researching how Python's sort(), lambda, and list methods work, and testing my code with each of them. This ultimately helped me better understand how lists and dictionaries work together and improved my problem solving skills. ]

2. Share one technical concept that you gained a deeper understanding of
   through building this project. Explain that concept in simple terms and
   explain how it is used in your project.

[One technical concept I gained a deeper understanding of was working with dictionaries and lists in Python. A list allows me to store multiple pieces of information, while dictionaries allow me to organize related information using the key-value pairs. In my quiz game, I used a list of dictionaries to store player names, scores, and dates for the high score leaderboard. This helped me understand how different types data work together and how the list and dictionaries organize and manage information in a program.]
