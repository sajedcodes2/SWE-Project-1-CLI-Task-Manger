# CLI Quiz Game App 
Project Description

The CLI Quiz Game is a command-line application that allows users to test their knowledge of some of the Capitals of United States of America through a multiple-choice quiz. Players can answer questions, receive immediate feedback on their answers, and see their final score and percentage when the quiz ends.

The game also includes a high score leaderboard that tracks the top three players based on their quiz percentages. Players who qualify can enter their names, and their scores are ranked from highest to lowest.

How to Use the Game:

When the application starts, the user is presented with three options:
Start Quiz: Begin answering multiple-choice questions.

View High Scores: Display the top three players on the leaderboard.

Exit: Closes the application.

Example Usage:

A player named Walker selects 1 to start the quiz.
The game displays a question and four possible answers:

Question 1: What is the capital of North Carolina?

1. Raleigh

2. North Park 

3. Charleston

4. Rome

Walker enters 2.

The game responds with:

Correct! or Incorrect! 

After completing all the questions, the game displays your final score and percentage.
For example:

Final Score: 4/5

Percentage: 80%

If Walker qualifies for the top three leaderboard, the game asks for their name and adds their score to the rankings.
